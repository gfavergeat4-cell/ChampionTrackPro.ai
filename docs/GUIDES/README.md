# GUIDES — fiches d'action

Une fiche par action importante. On les lit en 30 secondes, on sait quoi faire.

**Ce que c'est :** la procédure exacte, les pièges connus, le SQL de secours quand l'interface ne suffit pas.
**Ce que ce n'est pas :** de la doc technique. Le fonctionnement interne vit dans `docs/08_CARTOGRAPHIE_TECHNIQUE.md`.

| Fiche | Pour |
|---|---|
| [01 — Créer une équipe et attribuer les rôles](01_creer_une_equipe.md) | Gabin |

## Format d'une fiche

Cinq sections, jamais plus :

1. **En une phrase** — à quoi ça sert.
2. **Étapes** — numérotées, sans commentaire.
3. **Ce qui peut mal tourner** — les pièges réellement rencontrés, pas les hypothétiques.
4. **SQL de secours** — quand l'interface ne suffit pas.
5. **Ce qu'on dit au coach** — le script mot pour mot, uniquement si la fiche le concerne.

Une fiche qui dépasse une page à l'écran est trop longue : la découper.
